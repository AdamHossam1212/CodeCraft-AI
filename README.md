# CodeCraft AI — المرحلة الأولى

## ما الذي يعمل؟
- واجهة عربية بسيطة.
- المستخدم يكتب بالعربي أو الإنجليزي.
- اختيار: توليد كود أو كتابة محتوى.
- اختيار لغة البرمجة.
- اتصال حقيقي بـ OpenAI Responses API من السيرفر.
- زر نسخ النتيجة.
- مفتاح API لا يظهر في المتصفح لأنه محفوظ في `.env`.

## التشغيل
1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   npm install
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاح OpenAI في:
   OPENAI_API_KEY=...
6. شغّل:
   npm start
7. افتح:
   http://localhost:3000

## ملاحظة
واجهة OpenAI API ليست خدمة مجانية تلقائياً؛ الاستخدام يُحاسب حسب النموذج والحساب. لا تضع مفتاح API داخل `public/app.js` أو أي ملف يصل للمتصفح.
